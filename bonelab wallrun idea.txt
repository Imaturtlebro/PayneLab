# TASK: Implement Procedural Wallrunning & Wall-Jump System (PayneLab)

Implement a full active-ragdoll Wallrunning and Wall-Jump mechanic mapped to the Right Controller 'A' button (Jump hold).

### 1. State Machine & Enum Update
* In `PayneLab.cs`, add `StuntState.WallRun` to `enum StuntState`.
* In `PayneLabStateMachine.cs`:
  - Add fields:
    - `private bool _isWallRunning = false;`
    - `private Vector3 _wallNormal = Vector3.zero;`
    - `private bool _isWallOnRight = false;`
    - `private float _wallRunTimer = 0f;`
    - `private float _wallReleaseGraceTimer = 0f;`
  - Detection Logic in `Tick()` / `DetectMovementState()`:
    - When `_mod.CurrentState == StuntState.Aerial` and player is NOT grounded:
      - Fire two lateral raycasts from `CachedPelvisRb.position` (Left: `-transform.right * 0.9f`, Right: `transform.right * 0.9f`) using `PayneLabUtils.RaycastNonSelf`.
      - Check if wall hit is vertical (`Mathf.Abs(hit.normal.y) < 0.25f`).
      - If wall is found AND Right Controller 'A' is held (`rCtrl.GetAButton()`):
        - Enter `StuntState.WallRun`.
        - Capture `_wallNormal = hit.normal;` and determine `_isWallOnRight = (hit.point - pelvis.pos)` dot `transform.right > 0`.
  - Wallrun Physics Loop:
    - While in `StuntState.WallRun`:
      - If player releases 'A' (`!rCtrl.GetAButton()`) or reaches max wallrun time (`2.5s`) or loses wall contact:
        - Exit `WallRun` to `StuntState.Aerial`.
        - Start `_wallReleaseGraceTimer = 0.20f;` (allows jump-buffering after release).
      - If player presses 'A' down (`rCtrl.GetAButtonDown()`) while in `WallRun` or during the grace window:
        - Trigger `ExecuteWallJump()`.
  - Physics Forces in `WallRun`:
    - Calculate wall forward tangent: `Vector3 tangent = Vector3.Cross(_wallNormal, Vector3.up);` (ensure tangent aligns with player forward velocity via Dot product).
    - Counter gravity: Apply upward force `Vector3.up * 8.5f` (ForceMode.Acceleration) to slow descent.
    - Maintain forward momentum along `tangent` (`tangent * speed`).
    - Apply slight inward stick force (`-_wallNormal * 15f`, ForceMode.Acceleration).

### 2. Wall Jump Execution
* Method `ExecuteWallJump()`:
  - Calculate rebound impulse:
    `Vector3 jumpDir = (_wallNormal * 4.5f) + (Vector3.up * 5.2f) + (tangent * 3.0f);`
  - Apply `CachedPelvisRb.AddForce(jumpDir, ForceMode.VelocityChange);`
  - Set state to `StuntState.Aerial`.
  - Set `_actionLockTimer = 0.3f;` to prevent instant re-sticking.

### 3. Procedural Leg Stride & Torso Bank (`PayneLabLegPoses.cs`)
* In `ComputeWallRunPose()`:
  - Calculate run cycle: `float stride = Mathf.Sin(Time.time * 12f) * 35f;`
  - If `_isWallOnRight`:
    - **Right Leg (Wall-Side):** `RightHipTarget = Quaternion.Euler(stride, 25f, -15f); RightKneeTarget = Quaternion.Euler(45f + stride * 0.5f, 0f, 0f);`
    - **Left Leg (Air-Side):** `LeftHipTarget = Quaternion.Euler(-stride * 0.5f, -10f, 0f); LeftKneeTarget = Quaternion.Euler(30f, 0f, 0f);`
  - If `_isWallOnLeft`:
    - Mirror the poses for Left as Wall-Side and Right as Air-Side.
* In `PayneLabStabilizer.cs`:
  - When in `StuntState.WallRun`, tilt target up vector by 15° away from the wall normal to create the dynamic body bank/lean.
